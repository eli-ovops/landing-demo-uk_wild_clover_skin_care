# Design Intent — Wild Clover Skin Care v2

Created before code: 2026-08-23. Status: internal planning evidence only.

## Design read

An independent Shawlands facial therapist needs a calm **appointment-choice page**, not an anonymous luxury editorial or a booking-platform reskin. The audience is someone deciding which facial fits their skin and available time before entering the existing Ovatu flow.

## Brand-specific anchors

- **Clover’s practitioner identity:** official Instagram identifies “Clover | Facial Therapist”; the current booking profile exposes treatments by name. Source: `https://www.instagram.com/wildcloverskin/`; `https://wildcloverskin.book.app/book-now`.
- **Place:** The Fox Den, Shawlands, Glasgow. Source: `https://wildcloverskin.book.app/`.
- **Real visual identity:** one current public treatment photograph and the official Wild Clover logo, both served by the current official Ovatu page. They are used at minimum necessary scale for local concept identity, not as generic decoration.
- **Decision content:** Signature (£100/1h45), Bespoke (£75/1h15), Balance (£80/1h20); exact source is the current booking page and must be rechecked before any later reuse.

## Visual language and page rhythm

`identity panel → choose-by-need appointment matrix → concise practitioner-method strip → compact review evidence → location-led handoff`.

The layout uses sharp vertical rules, modest sans typography, compact price/time metadata and a real-photo side panel. It deliberately avoids the visual language of a magazine cover, a spa stock collage or a generic luxury landing page. The primary page action is always the existing booking route.

### Feedback revision — 2026-08-23

User feedback correctly identified display-size inflation as a false proxy for quality. The revised direction makes the actual treatment photograph, booking metadata, measured negative space and calm editorial rhythm carry the page. Headline scale is deliberately reduced; headings state location, service selection and booking purpose rather than perform luxury through oversized copy.

The revision also removes repetitive section labels: the only small-caps labels retained are the practitioner identity at arrival and the location-led booking handoff. This avoids a templated section rhythm.

## Explicitly avoided

- Generic AI spa still-life as hero; no AI image is used.
- One photo plus oversized serif headline; the hero is an identity/decision panel with restrained display scale.
- Three equal cards, giant review numeral, repeated CTA block and minimalist generic footer.
- Invented practitioner credentials, treatment outcomes, room details, reviews or client imagery.

## Closing strategy

`Specificity + Reassurance + Conversion`: the close states the verified Fox Den/Shawlands context, clarifies that live choices remain in the existing booking route, then offers that single route. It is not a generic “ready to” CTA.

## Identifiability answer

**Yes.** With the merchant name removed, the page remains identifiable by the actual Wild Clover photo/logo, Clover-specific facial menu/prices, The Fox Den/Shawlands context, and its appointment-choice architecture. Replacing these would require a new page, not a name swap.
